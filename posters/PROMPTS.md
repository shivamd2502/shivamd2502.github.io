# AI poster prompts (one per project)

Each project page starts with a wide poster. A designed poster is built in automatically. To use an
**AI-generated** poster instead:

1. Paste a prompt below into an image generator (ChatGPT / DALL·E, Gemini / Imagen, Midjourney, Firefly, …).
2. Ask for a **21:9 wide** image (e.g. 2100 × 900). Avoid text in the image; the site adds the title.
3. Save it as **WebP** (or PNG and convert) with the exact file name shown.
4. Put it in `D:\shivam_portfolio\site\public\posters\`. The site picks it up automatically.

Shared style for every prompt: *dark navy background, cyan and violet neon accents, cinematic lighting,
clean futuristic tech-poster look, high detail, no text, no logos, no watermark.*

**`clip-peft-land-cover.webp`**: Vision-language PEFT
> A glowing neural network bridge connecting a satellite view of Earth's land patches (forests, rivers, farmland, cities) on the left to floating natural-language text bubbles on the right; a small bright adapter module highlighted inside a large frozen transformer; search results appearing as image cards. Dark navy background, cyan and violet neon accents, cinematic, no text.

**`xray-stitching.webp`**: X-ray panorama
> Two overlapping translucent blue X-ray images of a human spine sliding together into one seamless panoramic radiograph; fine glowing feature-match lines connecting identical bone landmarks between the two images; a subtle geometric grid suggesting a homography transform. Medical-tech aesthetic, dark navy background, cyan and violet glow, no text.

**`eos04-sar-deep-learning.webp`**: Satellite radar + deep learning
> An Indian earth-observation radar satellite orbiting above mountainous Himalayan terrain, emitting C-band radar beams; below, the terrain turns into a colour-coded map of forest, mixed vegetation and urban areas, divided into a grid of square patches that flow into a convolutional neural network. Dark space background, cyan and violet accents, cinematic, no text.

**`iot-intrusion-detection.webp`**: IoT security with an autoencoder
> A network of glowing IoT devices (cameras, sensors, smart plugs) connected by data streams that funnel into an hourglass-shaped autoencoder; a compact glowing latent core in the middle; malicious red packets being filtered out while normal cyan packets pass. Cyber-security aesthetic, dark navy background, cyan, violet and a touch of red, no text.

**`hybrid-network-fault-diagnosis.webp`**: ML + expert rules

**`rl-active-suspension.webp`**: Reinforcement learning for suspension

Engineering-meets-AI aesthetic, dark navy background, cyan and violet accents, no text.
